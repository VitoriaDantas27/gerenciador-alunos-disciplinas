# Notas sobre os arquivos

Este repositório reúne arquivos locais de um trabalho acadêmico em dupla de Estrutura de Dados I.

- `src/` e `include/`: estrutura modular descrita no README original.
- `main.c`, `aluno.c`, `aluno.h`, `disciplina.c` e `disciplina.h`: outra organização de arquivos encontrada na pasta original, preservada para referência.

As duas organizações foram preservadas sem alterações de código. Não foi verificado se ambas compilam ou se representam a mesma versão do programa. O README original registra o estado do projeto em uma etapa de desenvolvimento e pode estar desatualizado em relação aos arquivos.

Os créditos da dupla constam no README original.
